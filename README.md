# 📝 Meu Blog

Projeto de blog desenvolvido como parte da minha prática em desenvolvimento web.

A proposta é criar uma página pessoal para apresentar conteúdos, projetos e informações de forma simples, organizada e responsiva.

## 🌐 Demonstração

🔗 [Acessar o projeto](https://meu-blog-six.vercel.app/)

## 🚀 Tecnologias

* HTML5
* CSS3
* JavaScript
* Vercel

## 📌 Funcionalidades

* Página inicial
* Apresentação pessoal
* Exibição de conteúdos
* Navegação entre as seções
* Layout responsivo
* Interface desenvolvida para acesso em diferentes dispositivos

## 📂 Estrutura do projeto

```text
meu-blog/
├── index.html
├── css/
├── js/
├── images/
└── README.md
```

> A estrutura pode variar de acordo com a organização atual dos arquivos do projeto.

## 🎯 Objetivo

Este projeto foi desenvolvido com o objetivo de praticar conceitos de desenvolvimento web, organização de páginas, estilização e criação de interfaces para a web.
